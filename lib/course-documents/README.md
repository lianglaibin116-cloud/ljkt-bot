# 课程资料

课程顶部与专业模式当前课程工具栏中的“课程资料”提供两种按需生成的资料：教师课程计划、学生课堂笔记。生成复用当前文本模型；可选的服务端模型路由键为 `course-documents`。

老师可按章节编辑、增删段落并保存。重新整理先产生候选稿，采用时先保存尚未保存的手动修改，再将当前稿保留为上一版。课件教学内容变化时提示更新资料；颜色、坐标及播放设置不参与内容指纹。

Word 下载与打印/PDF 均使用当前保存稿。Word 是真正的 OOXML 文件，包含原生 Office 公式、表格与保留换行的代码；PDF 通过浏览器打印为 A4，应用界面和另一份资料不进入打印内容。

## 内容来源

- 提取实际课件的文字、公式、表格、图表数据、代码、讲解与测验，大纲作为教学目标背景。
- 互动 HTML 通过惰性解析读取教学文字，不运行脚本或抓取外部互动链接。
- PBL 只提取教学设计，排除提交、聊天、评价等学生运行数据。
- 学生笔记附上全部测验；已有答案和解析原样保留。缺少的主观题答案标为“参考答案”。只有具体事实或安全错误、课件内部冲突，以及必需的题解或页面内容确实无法补齐时，才显示可展开的“需修正的内容”；普通资料缺省和教学范围说明不作为报错。提示不进入 Word/PDF 正文。
- 学生笔记直接整理知识要点，不附加修订、复习或学习自查清单。已有资料中的此类清单也从预览、编辑和 Word/PDF 中移除；实验步骤、安全检查与 PBL 完成标准作为教学内容保留。
- 长课程分块处理，教师提要按模型上下文预算逐层汇总，不裁去尾页。

## 存储与接口

`NEXT_PUBLIC_PERSISTENCE` 未启用时，资料写入 IndexedDB 独立的 `courseDocuments` 表。启用时，通过 `GET/PUT /api/stages/[id]/course-documents` 读写服务端 `course_documents` 表，并在服务端校验课程拥有者。两种方式均使用独立版本号阻止旧窗口覆盖新稿；课程删除时清理资料。

`POST /api/generate/course-documents` 接收 `kind`、`stageId`、`storageMode`；本机模式携带语义化 `source`，服务端模式重新读取拥有者的已保存课件。响应为 `progress`、`complete` 或 `error` SSE 事件。该请求只生成候选内容，不改写课程；持久化由资料仓库负责。

现有课件不需要内容迁移。现有 PPTX、HTML 和课堂 ZIP 的格式保持原样；资料当前通过独立 Word/PDF 文件分发。

## 验证

- `pnpm exec vitest run tests/course-documents`：来源提取、长课程、完整题解、资料版本、冲突、拥有者隔离和 Word 文件结构。
- `pnpm teacher:check`：包括以上用例以及已有教师版回归检查。
- `e2e/teacher/course-documents.spec.ts`：模拟模型响应的隔离浏览器验收，覆盖生成、修改、刷新、采用新稿、恢复、课件更新提示和 Word/PDF 导出，不调用真实模型。
