## 仍需单独处理的发布门槛

1. 真实编译器、Worker/WASM 资源需设计受支持的离线/在线运行适配器；当前兼容预检只能识别已静态暴露的依赖。
2. 安全复制课程前需要为课程文档、场景 ID、音视频/代理资源、任务和聊天室话题建立完整克隆契约。
3. 长任务需要独立于 iframe 生命周期的本机任务服务，支持取消、后台完成和退出后恢复。
4. 凭证需迁入 macOS Keychain / Windows Credential Manager 等系统安全存储，并在 Bot 内做旧配置迁移与失败恢复。
5. 发布版还需每次启动会话认证、DNS 重绑定和跨站写请求验证，以及代码签名、公证、自动更新和 Windows/macOS 安装包实机验收。

这些项是明确的当前限制，不表示已经验证或实现。`docs/2026-11-01-设计与实现审核.md` 保存修复前审核发现，阅读时以本记录的状态列为准。
