# 第一次试用灵境课堂 Bot

1. 双击 `desktop/release/灵境课堂 Bot-darwin-arm64/灵境课堂 Bot.app`，等待聊天窗口打开，无需启动原灵境课堂。
2. 点击左下角“模型与设置”，单独配置文本模型。在需要生成配音、图片或视频时分别配置对应服务。
3. 输入例如“制作一节八年级勾股定理课，6页，包含图形互动和随堂测验”。Bot会准备课程任务卡，点击“开始整理大纲”后审阅并确认大纲。
4. 课程完成后在工作区授课、进入专业模式修改，或打开课程资料。左侧“我的课件”也可以重新打开保存的课程。
5. 教师计划和学生笔记分别按需生成，保存后下载Word或打印PDF。课件使用原导出菜单选择PPTX或两种HTML版本，HTML继续保留离线画笔。
6. 普通知识问答直接在中间聊天。可以上传PDF、PPTX、DOCX、TXT或Markdown；关联课件后，Bot会读取当前保存的课件内容作为上下文。材料会在制作流程中实际解析，不把文件名当正文。
7. “新建对话”保留已有记录；停止按钮中止当前回复。关闭窗口只隐藏应用，菜单“退出”结束应用和本机服务。

已有课件请先从原灵境课堂导出，再到Bot的完整课件工作台使用原有导入入口。两个应用的课程和模型设置默认相互独立。

若启动端口30310被占用，先退出另一份Bot实例后重开。本应用不会强制关闭占用端口的进程。模型报错时已收到的回复与历史对话会保留，可以调整模型配置后重新发送。

本次是macOS ARM64本机测试版。无需将它误认为已完成Windows安装包、正式发行签名或自动更新。
