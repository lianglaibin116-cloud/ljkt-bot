# OpenMAIC v1.4.2 对齐记录

- 上游稳定版：`v1.4.2`，提交 `eb7c1bcccc3d083684c26ae1d5d187d41122cb10`。
- Bot 前一基线：共享包与 OpenMAIC `v1.4.1` 一致，另有 Bot 独立改动；当前 Bot 包版本：`0.2.3`。
- 已迁移：`@ljkt/generation` 0.3.31（互动库地址版本回退、组件大纲附加要求与设计意图）、`@ljkt/renderer` 0.2.1（激光指针定位）；保留本地模拟 Canvas 防失控生成约束。
- 已适配：TUN 代理 fake-ip 地址在明确启用 `ALLOW_LOCAL_NETWORKS` 时可用于服务端配置的模型提供方，客户端传入的公网地址仍按严格策略；互动页原有 HTML 不会被空值、占位符或单独 DOCTYPE 覆盖。
- 保留：Bot 独立聊天、工作区、课程制作流程和独立数据目录。未对 `/Users/sy/OpenMAIC` 进行写入。
- 已补齐：课程级撤销/重做覆盖手动页面编辑、页面增删/排序、旁白和动作、互动页内容与布局、角色阵容，以及工作台同步到达的 Agent 修改；按媒体引用和时间限制保留历史。
- 代码审核确认已有：VoxCPM 自动音色上下文、按模型配置思考参数、编辑器/播放页激光定位适配；技能包导出已改为 `ljkt/` 名称和内容。
- 暂未适配：PBL v3 项目运行时。Bot 只有 PBL v2，没有上游的共享沙箱、项目工作流、检查点和预览网关。官方实现要求先配置沙箱提供方；本机检查到 Docker daemon、PostgreSQL `DATABASE_URL`、Agent Runtime 与沙箱提供方配置均不可用，因此不启用入口或伪造本地运行能力。详见 [PBL v3 运行条件](./PBL-v3-运行条件.md)。
- 注意：撤销时间线存在于当前应用会话内存中，退出应用后不保留；课程内容本身仍按既有机制保存。
- OpenMAIC `v1.5.0-rc.2` 是预发布版本；当前仍以 `v1.4.2` 最新稳定版为基线，不把 RC 专属功能混入稳定版对齐。
- 上游发布说明：https://github.com/THU-MAIC/OpenMAIC/releases/tag/v1.4.2
